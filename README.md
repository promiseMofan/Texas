# 德州扑克单机版

一款支持电脑、iPhone 和 Android 的中文单机德州扑克。你将与三名不同风格的电脑玩家对局，手机安装并完成首次离线准备后即可断网游玩。

## 功能

- 标准无限注德州扑克流程：盲注、翻牌、转牌、河牌、摊牌
- 可见荷官与逐张发牌、烧牌翻牌、弃牌入弃牌区动画
- 下注、跟注、过牌、弃牌和全下
- 多人全下与边池结算
- 三种电脑策略风格及动态思考
- 简单、一般、困难三档AI难度
- 困难模式使用蒙特卡洛胜率估计与离线训练的抽象MCCFR混合策略
- 本地战绩、音效和游戏速度设置
- macOS DMG 与 Windows EXE 安装包
- 手机浏览器/PWA：iPhone（Safari）与 Android（Chrome）可添加到主屏幕，支持离线游玩
- 跟随手机系统自动横竖屏；竖屏上下排布，横屏把操作区放到牌桌右侧
- 自动保存牌局、筹码与底牌；中断发牌、切换应用或重开后可继续
- 明确显示离线准备是否完成，更新前保留进度，下载失败可重试

## 在手机上安装

安装网址：**https://promisemofan.github.io/Texas/**

### iPhone

1. 用 **Safari** 打开安装网址。微信、QQ 等内置浏览器中，请先选择“在 Safari 中打开”。
2. 点工具栏的 **分享**（方框向上箭头），向下找到 **添加到主屏幕**，然后点 **添加**。如果显示“作为网页 App 打开”，请保持开启。
3. 从主屏幕点“德州扑克”图标启动。**首次保持联网，等到显示“已可离线游玩”后再断网**。游戏设置中的“安装与离线状态”可以随时检查。

### Android

1. 用 **Chrome** 打开同一网址。
2. 点游戏的安装按钮，或用 Chrome 右上角 **⋮ → 添加到主屏幕 → 安装**（部分版本显示“安装应用”）。
3. 从主屏幕打开游戏，首次等到显示“已可离线游玩”。

这是可独立启动的主屏幕网页 App（PWA），无需 App Store、苹果开发者账号或电脑常开。它不是 IPA/APK 文件。

### 自动横竖屏、进度和更新

- iPhone 在控制中心关闭“竖排方向锁定”；Android 打开“自动旋转”。游戏跟随系统和浏览器根据设备方向自动切换布局，不需要额外授予陀螺仪权限。
- 旋转不会开始新牌局。横屏采用左侧牌桌、右侧操作区，并为刘海和屏幕底部留出安全区域；小屏手机可滚动查看记录。
- 牌局保存在当前浏览器/安装实例里，重开自动继续。动画中退出时，从最近一个完整动作继续；已支付的下注和已结算的底池不会重复计算。
- Safari 与主屏幕 App 的存储可能独立，建议安装后一直从主屏幕图标启动。清除网站数据或卸载并清除数据会丢失存档。
- 新版本下载完成后，可在设置中点“保存进度并更新”。如果以前安装的旧版本没有更新按钮，请联网关闭旧网页和游戏窗口，再从主屏幕重新打开。
- 如果显示离线准备失败，保持联网后点“重新准备离线内容”。设备系统回收网站缓存后也需要重新联网准备一次。

## 手机网站构建与验证

推荐 Node.js 20 或更新版本。手机网站本身没有运行时依赖。

```bash
npm run build:web
```

发布 `dist/web/` 中的内容即可；此目录只含游戏网页与素材，不含 Electron、依赖目录、Git 元数据或测试文件。支持部署在网站根目录，也支持 `/Texas/` 这样的子目录。构建脚本按文件内容生成缓存版本，资源变更时会触发更新。

当前 GitHub Pages 地址使用仓库 `main` 分支根目录。根目录保留 `.nojekyll`，发布网页改动时应同步修改 `sw.js` 的 `BUILD_REVISION`，以便现有安装下载新版本。若重新配置 Pages，在 **Settings → Pages** 中选择 **Deploy from a branch → main → /(root)**。

浏览器集成验证：

```bash
npm test
npx playwright install chromium webkit
npm run build:web
npm run test:mobile
```

使用隔离的 WebKit 与 Chromium 测试 iPhone/Android 尺寸、发牌中旋转、离线冷启动、完整对局、中断发牌与弃牌后的恢复、更新、存储不可用和缓存下载失败。截图保存在 `dist/mobile-checks/`。这属于浏览器内核与设备尺寸模拟，真机的系统安装菜单和旋转锁定仍由手机管理。

只预览手机布局：

```bash
npm run serve
# 或预览构建产物
npm run serve -- --dir dist/web
```

终端会打印同一 Wi-Fi 下的手机访问地址。局域网 HTTP 地址只用于预览，不能完成离线安装；正式安装请用上面的 HTTPS 网址。`localhost`/`127.0.0.1` 仅在电脑自身用于离线功能开发验证。

## 原生 APK / iOS 安装包

PWA 是目前成本最低、同时覆盖 iPhone 和 Android 的方案，不需要 App Store 审核，也不需要分别维护两套牌局代码。如果必须生成 Android APK 或提交苹果 App Store，可以在这套 Web 版本稳定后再用 Capacitor 包装；Android 需要 Android Studio，iOS 需要 macOS + Xcode 和苹果开发者账号。Electron 生成的 DMG/EXE 不能直接安装到手机。

AI训练在开发阶段离线完成，App运行时只读取生成的平均策略，不联网，也不会读取任何电脑玩家不应知道的底牌。
